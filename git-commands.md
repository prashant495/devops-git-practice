1. git init -> Initializes a Git repository in the current folder by creating a .git directory.

2. git status -> Shows the current Git status, including modified, staged, untracked, and committed changes.

3. git clone -> Copies an existing remote repository to your local machine and automatically configures the remote as origin.

4. git add -> Moves changes from the working directory to the staging area. Example: git add file.txt or git add .

5. git commit -> Saves the staged changes as a commit in the local Git repository.

6. git push origin master -> Pushes commits from your local main branch to the remote main branch. master can also be used if that is your branch name.

7. git pull origin master -> Downloads changes from the remote main branch and merges them into your current local branch.

8. git fetch -> Downloads information/commits from the remote repository without merging them into your current branch.

9. git checkout -b dev -> Creates a new dev branch and switches to it.

10. git checkout branchname -> Switches from the current branch to the specified branch.

11. git merge main -> Merges the main branch into your current branch.

12. git revert -> Creates a new commit that reverses the changes introduced by an earlier commit.

13. git rm file1.txt -> Removes file1.txt from the working directory and stages its deletion for the next commit.
