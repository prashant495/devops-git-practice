1. git init -> to initialize the folder

2. git status -> it will show you the current status of files inside that folder like tracked and untracked files

3. git clone -> Copy a remote repository locally

4. git add -> it will ready the new files in staging area

5. git commit -> Save changes to local repository

6. git push origin master -> it will push the changes from loacl repo to remote repo master/main branch

7. git pull origin master -> it will pull the changes from remote master branch to local repo

8. git fetch -> it will download remote changes without merging

9. git checkout -b dev -> it will create one new branch named as dev

10. git checkout branchname -> it will switch to that branch

11. git merge main -> it will merger the current branch with main branch

12. git revert -> it will undo the changes

13. git rm file1.txt -> it will delete the file1 from git
